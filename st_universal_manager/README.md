# ST Universal Manager — 0.1.6 개발 후보
HA OS/Supervised의 amd64/aarch64용 관리 애드온. 기존 Edge 런타임은 변경하지 않고 별도 관리 UI를 추가합니다.

설치: HA 설정 → 앱(애드온) → 앱 스토어 → 저장소 → https://github.com/cleverk2000-code/ST 추가 → ST Universal Manager 설치 → 시작 → 웹 UI 열기. Docker 이미지 빌드 시 npm/GitHub 연결 필요. HA OS/Supervised가 아닌 HA Container/Core는 앱을 지원하지 않습니다.

PC 필요 없음: 스마트폰에서 SmartThings 임시 PAT 발급 후 웹 UI에 입력. 기존 Windows CLI 세션은 이전하지 않습니다. PAT는 브라우저 세션별로 애드온 메모리에만 최대 23시간 보관하며 CLI 명령에는 명시적 --token으로 사용합니다. 언제든 지우기 버튼으로 제거할 수 있습니다. 발급 시점부터 24시간 유효하므로 서버 만료는 더 일찍 발생할 수 있습니다. 권한 부족/만료 시 중단합니다. 삼성 API 정책 및 계정별 Edge 권한에 따라 임시 PAT가 패키징 권한을 제공하는지 실제 검증 필요. OAuth 자동 로그인은 미구현.

기본 7개 패키지는 기존 설치에 맞춘 것입니다. `zcl-controls` (ST MQTT ZCL Controls)는 별도 선택 항목입니다. 처음 설치할 때 해당 항목만 선택하고 신규 설치 허용을 체크한 뒤 사전 검증 및 업데이트를 실행하세요. SmartThings에서 호환 기기의 드라이버를 ST MQTT ZCL Controls로 변경해야 합니다. 기존 원본 드라이버와 기기는 삭제하지 않습니다. 버튼 이벤트는 기존 MQTT 이벤트 훅이 지원되는 경우 component별 HA event 엔티티로 노출됩니다. hub/channel ID는 사용자 입력값으로만 사용합니다. 먼저 '기존 드라이버 확인'을 실행하세요. 소유 packageKey, 허브 설치 ID, 채널 할당 ID 및 채널을 대조합니다. '빌드 및 사전 검증'은 업로드 없음. '업데이트 실행'은 승인 체크 후 같은 packageKey로 업로드하고 반환된 driverId가 기존과 동일한지 확인한 뒤 버전 할당 및 설치합니다. ID 변경이면 할당/설치하지 않습니다. 성공 설치 버전을 다시 조회합니다. 중간 실패 시 자동 롤백하지 않으며 로그에서 이미 적용된 패키지 확인. 신규 설치는 별도 승인 옵션이며 기기 드라이버 변경은 하지 않습니다.

공통 MQTT 내장을 선택하면 기존 Master 설정 대신 로컬 파일에서 받은 공통 연결 정보를 빌드에 삽입합니다. 기본 site home, 패키지 family, 기존 토픽/unique_id 및 설정 필드 유지. 기기별 Export OFF는 계속 유효. GitHub에는 암호 없음. 단, 개인 빌드 패키지는 삼성 서버에 업로드되므로 암호가 패키지에 포함됩니다. 전용 최소 권한 MQTT 계정 사용 및 채널 비공개 유지 권장. 저장 선택 시 애드온 /data에 0600 파일로 저장하며 HA 백업에 포함될 수 있습니다. PAT는 저장하지 않습니다. 임시 빌드는 작업 완료 후 삭제. 빌드 캐시는 원본 공개 소스만 보존. 내장 없이 업데이트하면 기존 Master 설정 사용. 기존 기기 및 HA 엔티티 ID 유지 목표이며 실기 검증 전까지 한 패키지씩 적용 권장.

현재 UI는 기존 7개 관리, ZCL Controls 선택 설치 및 신규 설치 옵션에 집중합니다. 타사 소스 등록 UI, 자동 드라이버 변경, Rules 관리, 자동 원본 업데이트 및 지속 OAuth는 미구현. 실제 HA 설치·삼성 인증·업데이트 테스트 전 개발 후보입니다.
